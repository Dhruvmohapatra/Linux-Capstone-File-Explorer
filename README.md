\## 🌟 What is this project?



\*\*Linux-Capstone-File-Explorer\*\* is a terminal-based file management application developed in \*\*C++ for Linux\*\*.



Instead of depending on graphical file managers, this project provides a simple menu-driven interface for performing common Linux file and directory operations directly from the terminal.



The project also goes one step further by including a \*\*custom Linux Character Device Driver\*\*.
